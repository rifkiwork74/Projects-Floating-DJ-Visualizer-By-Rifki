# Floating DJ Visualizer — V3.0.18.6

**Equalizer UX, Themed Safety Dialogs & Portable General Backup**  
Version code: **101**  
Baseline: **V3.0.18.5 (version code 100)**

## Equalizer

- Bass Boost and Virtualizer now use horizontal oval mixer-style fader caps, matching the visual language of the EQ band controls.
- **Save To** lists only compatible user-created presets. Built-in 5-band and 10-band library presets are excluded from overwrite targets.
- Built-in presets are protected from rename and delete actions.
- Overwrite and delete actions require an app-themed Yes/No confirmation that identifies the affected preset.
- Resetting an individual band now asks for confirmation and shows its current dB value and the target `0.0 dB`. Only the selected band is changed.
- Preset action labels use one-line, ellipsized, auto-sized text to avoid wrapping/clipping on narrow screens and default DPI settings.
- Save As and Rename use a responsive app-themed input dialog rather than stock system dialog buttons.

## Notification and Visualizer stop behavior

- Notification text in **GLASS** and **CUSTOM** follows the phone's system appearance: dark text in Light mode and white text in Dark mode.
- Explicit **LIGHT** and **DARK** theme modes retain their configured text colors.
- Stopping the Visualizer now requires confirmation. The confirmation explains that the Floating Overlay and Visualizer notification will be removed.
- Confirmed Stop terminates `FloatingVisualizerService` only. It does not stop `EqEngineService`; the EQ engine and its separate notification remain independent.
- The Stop action in the Visualizer notification opens the same confirmation dialog.

## General Settings backup

- Import accepts portable scalar preference entries even when a preference key has not yet been created on the receiving device.
- Known local preference types are respected; otherwise JSON scalar types are preserved.
- Runtime service state, MediaProjection/session values, and Android permission grants are not transferred or replayed.
- Import accepts UTF-8 BOM files and up to 4 MB, and reports a more specific error in the toast and application log.
- Source-device running state is informational. Import does not silently start Visualizer, Floating Overlay, EQ, or MediaProjection on the receiving device.

## Audio engine baseline

The V3.0.18.5 audio-engine code is intentionally left unchanged. No changes are made to PCM/stereo analysis, FFT, Hop Size, Single 256-band analysis, or M.Projection capture lifecycle.

## Validation status

The CAPROJ archive and static project structure are checked. Android `assembleDebug`, on-device UI validation at multiple DPI settings, independent EQ notification behavior, and physical cross-device export/import still require CodeAssist/device testing; they are not claimed as completed here.
