# Floating DJ Visualizer V3.0.18.7

**Current State Preset Flow · Linked Layers · Restart Restore**  
Version Code: **102**  
Baseline: **V3.0.18.6**

## Equalizer

- The per-band reset confirmation now chooses its YES label color from the measured contrast against both Theme Studio accent-gradient stops. Light or gold custom accents use dark lettering; dark accents use white lettering.
- Current State remains a separate working snapshot, independent of named preset records. A dedicated Current State entry is initialized on first launch, so the first saved-preset switch also follows the Yes/No flow.
- Selecting another saved preset while Current State or edited working values are active displays a Yes/No confirmation. Yes saves the latest band and effect values into Current State and then applies the chosen preset. No stays on Current State and leaves the current values active.
- Applying a preset no longer silently writes that preset over Current State.
- Save To uses the same visual row language as the main EQ preset dropdown and lists only compatible user-created presets. Built-in presets remain protected.

## Visualizer Stop / Start

- The last requested Floating and M.Projection modes are remembered when Visualizer Stop is confirmed.
- Start restores Floating when it was previously requested and overlay permission is granted.
- If M.Projection was previously enabled, Start requests Android MediaProjection consent again. Its previous authorization token is not reused.
- EQ Engine and its separate notification remain independent from Visualizer Stop.

## Floating Profile Linked

A new Linked control appears immediately to the left of the Position action in each layer row.

Linked members share only two behaviors:

1. **Position:** X/Y movements apply the same effective delta to linked layers while retaining each layer's own position offset. Screen-edge clamping is accounted for. Dynamic drag release also propagates the final delta.
2. **Visibility:** Hide or show from one linked member toggles the complete linked group.

Rename and Delete always remain per-layer. They are never propagated. New layers start unlinked. Unlinking or deleting a member cleans up a group when only one member remains. Canceling a Position dialog restores the original positions of linked members.

## Audio engine protection

The tested V3.0.18.5 audio engine remains unchanged. No PCM/Visualizer capture, stereo FFT, Horizontal or Single/DJ analysis, calibration, FFT size, Hop Size, or M.Projection worker logic was modified for this release.

## Validation note

Device verification is still required for dialog contrast, Current State switching, Stop/Start consent flow, and multi-layer Linked interactions.
