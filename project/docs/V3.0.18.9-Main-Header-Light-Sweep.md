# V3.0.18.9 — Main Header Light Sweep & Theme Studio Sparkle

## Reference observation
The supplied MP4 is approximately 10.03 seconds, 1280×720, encoded at 24 fps. The visible treatment is a multicolor title gradient with a narrow diagonal luminous slash moving across the title, followed by a short, sparse sparkle field. The implementation adapts that treatment to the existing `FLOATING DJ` title rather than reproducing the reference mockup's unrelated navigation chrome.

## Implementation
- `BrandShineDrawable` draws a diagonal accent-colored glow, a pale edge bloom, a narrow white core, and 12 deterministic sparkle points.
- The drawable is attached to `txtVisualizerTitle` through `ViewOverlay`, so the existing XML layout and title typography remain unchanged.
- The existing title gradient and the added shine share one `ValueAnimator` progress value. The animation loops over 3.6 seconds and is scheduled by Android's animation/Choreographer pipeline; it does not force 60 fps or assume every device can sustain a particular frame rate.
- Theme colors are refreshed from `currentAccent()`. In CUSTOM mode the configured edge color is respected; built-in GLASS, LIGHT, DARK, and SYSTEM retain their isolated palettes.
- The animation is enabled only while the Visualizer is ACTIVE. It is reset on pause/stop and the drawable is detached on destroy.

## Performance and compatibility notes
- The renderer uses a small fixed particle set, simple Canvas strokes/circles, and no bitmap generation, runtime blur, RenderEffect dependency, or extra worker thread.
- Rendering naturally follows the display refresh cadence available on the device. Actual sustained frame rate remains device/GPU dependent and must be verified on target hardware.
- Minimum SDK remains 26. The audio service, capture pipeline, FFT/Hop settings, EQ engine, Floating renderer, and user profile persistence are not changed.
