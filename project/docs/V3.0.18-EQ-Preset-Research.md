# V3.0.18 EQ Preset Research & Band Detection Notes

## Scope

This note records the external references and implementation choices used for the V3.0.18 default 5-band and 10-band EQ preset library. A curve is a starting point, not a universal tuning target: headphone/speaker response, fit, playback level, and recording vary. Users should compare against a familiar track and make small adjustments.

## Detect the engine before filtering presets

Android's `Equalizer` API exposes `getNumberOfBands()` to report how many bands the active Equalizer supports and `getCenterFreq()` to report each band's center frequency in milliHertz. The app therefore uses its active `EqEngineController.bands()` result rather than a device-brand guess. The current DynamicsProcessing backend exposes its configured 10-band bank; the native Equalizer backend reports its actual band count and center frequencies. The library dropdown filters profiles to a matching number of points. When no backend controls are available yet, the UI shows the last locally detected count or prompts the user to enable EQ once to scan; it does not infer a band count from another device's export.

Android API reference: https://developer.android.com/reference/android/media/audiofx/Equalizer

## Preset families reviewed

The library includes neutral/flat, bass lift, deep bass, bass/treble or V-shape, treble lift, pop, rock, jazz, classical, EDM/dance, hip-hop, acoustic, warm, podcast/speech, vocal clarity, loudness, small-speaker, reggae/country, and less-harsh/clear variants. The 5-band Pop/Rock/Hip-Hop/Electronic/Podcast curves follow conservative examples from the five-band guide. The 10-band curves borrow the shape/family of current 10-band examples, but their gain values are reduced to modest levels rather than copying aggressive full-strength settings.

5-band genre guide (60/230/910/3.6k/14k grid): https://acusticax.com/en/learn-about-the-equalizer-settings-for-different-music-genres/

10-band presets and center grid: https://hapibits.com/echo/learn/best-10-band-equalizer-presets

10-band preset shape examples and clipping/headroom guidance: https://pro-media.io/audio-equalizer/

Additional common 10-band preset families (Flat, Bass, Treble, Voice, Podcast, Loudness, Pop, Rock, Less Boom, Less Hiss): https://motionshine.com/tools/audio-equalizer

## Safety and gain policy

- Built-in curves are intended to be modest and generally stay within approximately ±4 dB in this release.
- The preset curves only set EQ band gains. They do not enable preamp, Bass Boost, Virtualizer, limiter, or a hidden volume booster.
- Raising several bands increases peak level and can consume headroom. A flat or cut-first adjustment can be preferable to large boosts; no curve is guaranteed to avoid clipping for every source/device chain.
- No claim is made that a 5-band curve is acoustically identical to a 10-band curve. A preset is only shown when its point count matches the active engine's reported band count; custom presets for other counts remain stored but are hidden from the current dropdown.

## Persistence and compatibility

The starter library is seeded additively using stable built-in IDs. Existing saved or renamed presets are not overwritten. User-created presets remain stored independently, and the newest saved user preset is listed first within the matching band-count section. The EQ profile JSON schema is unchanged.
