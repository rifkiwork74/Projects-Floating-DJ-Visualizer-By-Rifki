# Floating DJ Visualizer V3.0.18.8

**EQ Control Lock · Save To Scroll Rail · Theme-Animated Visualizer Title**  
Version Code: **103**  
Baseline: **V3.0.18.7**

## Equalizer

- Save To now has the same vertical scroll indicator style and behavior as the preset dropdown, with a screen-aware list height.
- Rename/Save As button text now uses measured contrast against both accent-gradient colors. Bright Custom accents choose dark text when it is more readable.
- When the EQ master engine is OFF, preset selection, Save As (+), Save To, Rename, Delete, Flat, band faders, and editable effect panels are disabled with a muted grey appearance. The master EQ switch remains usable.
- Flat now asks for Yes/No confirmation and lists current non-zero band values before setting every active band to 0 dB. Cancel leaves the current settings unchanged.

## Main page

- “BACKUP AUDIO CAPTURE” is renamed to **“ENGINE AUDIO CAPTURE · M.PROJ”**. Indonesian: **“MESIN AUDIO CAPTURE · M.PROJ”**.
- The main Floating DJ title uses a horizontal gradient based on the selected Theme Studio accent. Studio Custom also uses its selected edge color.
- The gradient sweeps left-to-right only while Visualizer is active. While stopped, starting, or in error state, it remains still. Animation is paused when the Activity is not visible.

## Audio engine protection

The V3.0.18.5 audio-engine implementation remains unchanged. No capture source, MediaProjection lifecycle, stereo FFT, Single/DJ bank, Horizontal calibration, FFT, Hop, or EQ processing engine code was changed.
