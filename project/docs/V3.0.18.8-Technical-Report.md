# Floating DJ Visualizer V3.0.18.8 Technical Report

## Scope

Baseline: V3.0.18.7 (versionCode 102)  
Output: V3.0.18.8 (versionCode 103)

This update addresses the remaining Equalizer UI issues and the main-page Theme Studio title treatment. The tested V3.0.18.5 audio-engine baseline is preserved.

## 1. Save To scroll indicator

`EqualizerActivity.showSaveToPresetDialog()` now places the target list in a horizontal row containing the existing `EqVerticalIndicatorView`, matching the vertical scroll rail already used by `showPresetDropdown()`. The list viewport is sized from target count but capped by the display's available height. The indicator refreshes on scroll and layout changes.

## 2. Rename dialog text contrast

The Rename/Save As dialog's primary SAVE label no longer decides between dark and white text from the overall Light/Dark theme flag. It computes the minimum contrast of each candidate against both actual accent-gradient stops and selects the stronger candidate. This handles Studio Custom colors such as pale gold or other light accents.

## 3. EQ master OFF state

A dedicated registry tracks the UI groups that depend on the master EQ engine: preset selector/Save As, preset action buttons, band canvas and scroll rail, plus editable Preamp/Bass Boost/Virtualizer/Limiter panels. `updateEqMasterControlGate()` recursively disables/enables descendants and mutes the group alpha while the engine is OFF. It is applied before per-effect capability checks, so controls unsupported by the active backend remain disabled even when the master engine is ON. The master switch itself remains available to turn EQ back ON.

## 4. Flat confirmation

`resetFlat()` now previews current non-zero band levels and requires a themed Yes/No confirmation before applying the Flat profile. Up to eight current band values are listed; if more are non-zero, the message reports the additional count. Confirming applies 0 dB to all currently exposed bands, updates the active profile, reloads presets, and persists Current State. Canceling leaves the EQ untouched.

## 5. Main-page capture label

The main-page source card label changes from “BACKUP AUDIO CAPTURE” to “ENGINE AUDIO CAPTURE · M.PROJ”, with an Indonesian localization entry “MESIN AUDIO CAPTURE · M.PROJ”. No source-routing behavior changes.

## 6. Theme Studio animated title

The main header brand TextView receives a Theme Studio gradient shader. The base and highlight colors derive from `currentAccent()`; CUSTOM mode also uses the selected `themeEdgeColor`. A left-to-right `ValueAnimator` translates the gradient only when the main engine status is ACTIVE. STOPPED/ERROR/STARTING states use a static gradient. The animation is canceled on Activity pause and destroy and rebuilt after theme/configuration changes.

## 8. Validation and limitations

- CAPROJ archive integrity and entry list checked after packaging.
- XML parsing and resource count checked.
- `module.toml` versionName/versionCode checked.
- Kotlin source delimiter balance and changed-block inspection performed.
- A full Android Kotlin type/build validation was not available: this runtime has no Android SDK `android.jar` or Gradle Android build environment. Do not treat the static checks as a successful `assembleDebug` build.
- On-device checks remain required for save-to scrolling, Studio Custom Rename contrast, EQ OFF interaction blocking, Flat confirmation, title animation timing, and capture-card wording in Indonesian/English.

## 9. Recommended device test sequence

1. Turn EQ OFF. Verify the preset dropdown, Save As (+), Save To, Rename, Delete, Flat, band faders, and editable effect controls are visibly muted and cannot be activated. Verify the master EQ switch can still turn EQ ON.
2. Turn EQ ON. Confirm backend-unsupported effect controls remain individually disabled.
3. Add enough compatible custom presets to overflow Save To; verify the scroll rail moves and matches the dropdown behavior.
4. Use a pale/gold Studio Custom accent; verify Rename/Save As SAVE text is dark and readable. Test a dark accent too.
5. Select Flat with non-zero bands. Verify the preview and cancel path; then confirm and verify all exposed bands become 0 dB.
6. Change Theme Studio colors, start Visualizer, and verify the title gradient moves horizontally. Stop Visualizer and verify the gradient remains static; resume and rotate the device to confirm the shader is rebuilt.
7. Confirm the source card label is localized as expected.
