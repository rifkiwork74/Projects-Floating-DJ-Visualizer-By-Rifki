# Floating DJ Visualizer V3.0.18.4

## Horizontal Spectrum Response Recovery

This update focuses on Horizontal mode while preserving the V3.0.18.3 Single/DJ recovery.

### Changes

- Removes full-frame peak normalization from MediaProjection PCM Horizontal analysis, preventing unrelated loud frequencies from changing the gain of other bars.
- Uses a restrained RMS-preserving aggregation across the 64-band map so concentrated vocal and bass notes are not diluted by a plain arithmetic average.
- Applies Horizontal-only level shaping to the Android output-mix Visualizer data. The validated Single/DJ bank and its calibration remain unchanged.
- Keeps Live Display and Floating Overlay on the same Horizontal aggregation rule.

### Preserved

Single/DJ 256-band analysis, Hz range selection, FFT/Hop options, time-based response settings, geometry, appearance, profiles, permissions, and audio routes are unchanged.

The CAPROJ structure, source consistency, metadata, and synthetic calculations were checked. Android `assembleDebug` and real-device playback tests have not been run in this environment. Please import into CodeAssist and test both M.Projection OFF and ON, then recheck Single/DJ.
