# V3.0.38.1 — Display Geometry Parity & Hold Ring Compile Fix

- **Compile fix:** declare the missing `expandingWindowPaint` used by `ScrollNavigatorButton`. It is a reusable anti-aliased stroke paint, so the expanding glass-window effect compiles and draws as an outer ring rather than a filled disc.
- **Hold interaction:** keep the 1.5s hold, 68dp measured touch target and 94% → 118% button scale. The new outer ring follows the same hold progress and is clamped inside the measured control bounds so it remains visible instead of being hidden behind the enlarged button or clipped at the edge. Tap navigation and early-release cancellation are unchanged.
- **Display/Floating horizontal parity:** correct the preview width budget to match the active layered `FloatingSceneSpectrumView`: only the inter-bar gaps reduce the drawable-body width. The preview's small halo buffer is retained for drawing, but it no longer consumes the configured bar-thickness budget. Split negative outer margins keep the actual body positions and gap identical to the floating renderer.
- **Header beam safety:** make the two-space left gutter a hard minimum. Remove the forced 12dp dash minimum that could override the safety gutter on narrow layouts; the beam is skipped when there is not enough safe space. Keep the one-space `• Floating DJ` title, 1.5-space bullet clearance, 2.5-space endpoint gap and shared 8.0s animation timeline (slightly faster than 8.6s, with the same 600ms bloom, 1.8s entry spin, overlapping 1.8s endpoint turn and 200ms fade).
- **Profile and Global Analysis audit:** verify the Live Preview picker changes both the active edit profile and preview target; horizontal profiles show their frequency strip and band labels, while Single profiles hide them. Global Audio Analysis remains shared FFT/Hop controls without a Floating Profile picker; the Response Engine retains its profile-aware selector.
- **Canvas sizing:** retain the responsive monitor viewport at 174dp portrait / 196dp landscape. It continues to cap preview height without changing the service's configured overlay size.
- **Preservation:** no changes to audio capture, MediaProjection PCM, FFT/Hop processing, Response calculations, EQ DSP, profile/scene persistence, notification controls, or launcher identity. `targetSdk 36` and `minSdk 26` remain unchanged.
