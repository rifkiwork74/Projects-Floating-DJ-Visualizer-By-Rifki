# V3.0.38.2 — Exact Display Gap & Symmetric Header Beam Transitions

- **Single Display:** the 24-segment Live Preview uses the fitted-height ratio between the selected Floating layer and the compact Display canvas for longitudinal segment geometry (gap, minimum segment height and radius). The horizontal bar thickness remains unchanged. This preserves the Floating segment-to-gap proportions in the smaller monitor canvas.
- **Horizontal Display:** both thickness and inter-bar gap use the same horizontal viewport-fit ratio. The preview calculates effective glow padding after applying the same width and height clamps used by `PreviewBarView`, then compensates child margins using that effective inset. A clipped halo can no longer silently change the visible gap.
- **Header beam:** entrance reaches full length/opacity in 200 ms with quintic smootherstep. The final 200 ms applies the inverse contraction from full length to 10% while fading to zero. Both ends share the same invisible 10%-length/0-alpha seam state.
- **Rotation unchanged:** `DURATION_MS`, `BLOOM_END`, `SPIN_END`, `TURN_START`, and `TURN_END` retain their V3.0.38.1 values. Only beam reveal progression and ending length scale change. The existing `ValueAnimator` continues to use Android frame/vsync scheduling; actual frame rate depends on the device refresh rate and runtime workload.
- **Version metadata:** `app/module.toml` and the root Android manifest both declare `versionCode=126` and `versionName=3.0.38.2`.
- **Preservation:** audio engine, PCM/Visualizer capture, FFT/Hop, EQ DSP, Floating renderer and scene/profile data formats are not changed.
